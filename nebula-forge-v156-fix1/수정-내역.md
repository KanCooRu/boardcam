## 고친 것

### 서버 보호
- **새 계정 첫 저장**: 서버가 만든 새 게임과 비교합니다. 서버가 준 적 없는 다이아·방지권·강화 단계·소환 결과가 있으면 직업과 설정만 남기고 새 게임으로 저장합니다.
- **재화 증가 한도**: 골드, 성운석, 강화석, 별철, 조각, 소환권, 스킨 코인, 입장권, 레벨, 최고 스테이지, 던전 단계, 시즌 점수는 게임 공식으로 계산한 "쉬지 않고 플레이했을 때의 최대치"까지만 저장됩니다. 넘는 부분만 깎고 저장 자체는 거부하지 않습니다.
- **서버만 주는 재화**: 동료 소환권·동료 조각은 기기에서 늘릴 수 없습니다. 소환권은 하루 22장(월드보스), 스킨 코인은 하루 26개(탐험대)까지만 기기에서 늘어납니다.
- **무료 입장 횟수**: 같은 날 안에서는 사용한 횟수를 되돌릴 수 없습니다.
- **보상 조건**: 퀘스트, 일일·주간 임무, 활약도 상자, 업적, 신규 기사 미션은 서버 기록에서 조건을 달성했을 때만 지급합니다(전에는 조건 확인 없이 지급).
- **한정 룰렛 코인**: 목록에 있는 미션마다 1개만 셉니다(전에는 수령 목록 길이만큼 무료 뽑기 가능).
- **오늘의 탑 순위**: 서버가 저장된 캐릭터로 직접 계산한 층수 + 3층까지만 기록합니다.

### 밸런스
- 무기 파괴 확률: +15부터 `4,5,6,7,8,9,10,11,12,14`%로 올렸습니다(이전 `2,2,3,3,4,4,5,5,6,7`).

### 화면
- 홈 화면의 12px 미만 글자를 모두 12px 이상으로, 44px보다 작은 버튼을 44px로 키웠습니다(우편함, 전체 메뉴, 재화 버튼, VIP, 보상 받기, 채팅 바, 전투 패배 안내 버튼).
- 세로가 짧은 화면(700px 이하)에서는 전투 화면이 줄지 않도록 재화 줄과 채팅 바를 예전 높이로 둡니다.

## 확인한 것

## 아직 남은 것
- 능력 강화·유물·동료·스킬 레벨·장비를 저장 파일에서 직접 고치는 조작은 막지 못합니다. 이 구매들을 서버 명령으로 옮겨야 합니다.
- 월드보스 다이아 보상은 기기가 보고한 피해량으로 정해집니다(하루 최대 2,700).
- 사용자 구분은 여전히 호스팅이 넣어 주는 ID 하나입니다. 앱 출시 전에 자체 로그인이 필요합니다.
- 한도는 "가능한 최대 속도"에 맞춰 넉넉하게 잡았습니다. 실제 플레이 기록이 쌓이면 더 조일 수 있습니다.
