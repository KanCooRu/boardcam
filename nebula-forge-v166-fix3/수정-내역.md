# 성운의 모루 웹 v166 수정본 3 (v166-fix3)

v166 위에 덮어쓰는 묶음입니다. 바뀐 파일만 담았고, 수정본 1·2의 내용도 들어 있습니다.

## 바꾼 것

- **스킬·동료 강화에 드는 조각을 등급별로 차등.** 레벨별 기본 비용(스킬 `10 + 레벨×1.5`, 동료 `10 + 레벨×2`)에 등급 배수를 곱합니다.
  - 스킬: 일반 ×1 · 희귀 ×1.5 · 영웅 ×2 · 전설 ×3
  - 동료: 일반 ×1 · 희귀 ×1.2 · 영웅 ×1.5 · 전설 ×2 · 신화 ×2.5 · 천상 ×3
- **중복 소환 때 받는 조각도 같은 배수.** 기본 10~20개 × 등급 배수입니다. 새로 얻을 때 받는 양(스킬 5개, 동료 0개)은 그대로입니다.
- 이미 올린 레벨은 그대로 두고, 앞으로 하는 강화에만 새 비용이 적용됩니다.
- 소환 확률 안내 문구에 배수를 적었습니다.
- 서버 규칙(`dist/server/rank-simulation.js`)도 같은 계산을 씁니다.
- 파일: `web/game/economy-rules.js`, `web/game/progression.js`, `web/game/wardrobe-catalog.js`, `dist/client/collection.js`, 테스트 `tests/collection-rewards.cjs`
