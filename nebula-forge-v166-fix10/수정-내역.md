# 성운의 모루 웹 v166 수정본 10 (v166-fix10)

v166에 수정본 1~10을 모두 적용한 전체 웹 버전입니다. Unity 폴더는 뺐습니다.

## 수정본 10 · 데미지 숫자 통일과 UI 다듬기(이번)
- 월드보스와 레이드의 데미지 숫자를 스테이지와 같게 맞췄습니다.
  - 표시 방식: `−12.5K`
  - 치명타: 금빛 기울임체, 별, 폭발 효과
  - 레이드: 숫자가 없었는데, 이제 내 공격에 숫자가 뜹니다.
- 버튼
  - 금색·보라 버튼에 입체감(빛 반사, 아래 그림자, 금테)을 넣었습니다.
  - 누르면 살짝 눌립니다.
- 켜기/끄기 스위치: OFF는 어두운 색, ON은 빛나는 비취색입니다. 예전에는 OFF가 주황빨강이라 켜진 것처럼 보였습니다.
- 팝업: 금빛 후광과 제목 아래 금빛 구분선을 넣었습니다.
- 상단 바로가기 줄: 오른쪽 끝을 흐리게 해서 넘길 수 있다는 표시를 했습니다.
- 하단 메뉴: 지금 탭 위에 금빛 선이 생깁니다.
- GPT 작업을 돕는 도구를 추가했습니다.
  - 자가 검사: `python3 tools/check-gpt-art.py`
  - 카드별 안내도: `art/gpt-guides/`
  - 지시서 0-2절: 만드는 순서, webp 변환 코드, 투명 배경 대처, 화면 확인 방법
- UI 그림 슬롯을 연결했습니다(A17~A19: 버튼, 팝업 테두리, 구분선, 탭 빛, 스위치 `UI_KIT_ART`). 그림을 켜도 버튼·팝업 크기는 바뀌지 않습니다.

## 수정본 9 · 스킬 효과를 부드럽게
- 스킬 60종의 효과 그림을 16장에서 36장으로 늘렸습니다. 원본 그림 사이를 섞어 중간 장면을 만들어서, 몇 장을 넘기는 느낌 대신 이어서 움직입니다.
- 재생 시간을 1.4배(0.6~1.1초)로 늘리고, 사라지는 끝부분을 더 천천히 흐리게 했습니다.
- 새 파일: `assets/skill-casts/<이름>.s36.avif`(1920×1920), `.s36.webp`(960×960). 원래 16장 파일은 Unity 시험 렌더러용으로 그대로 둡니다.
- 도구: `tools/bake-skill-effects-smooth.py`. 피해·시간 규칙은 바뀌지 않습니다.

## 수정본 8 · 전투 연출
- 스테이지 진행 경로를 새로 그렸습니다. 삐뚤던 보스 아이콘을 좌우 대칭 해골 문장으로 바꾸고 정중앙에 맞췄습니다.
- 스테이지 보스·던전·오늘의 탑에 상단 보스 체력 창을 넣었습니다(여러 줄 체력, 흰 잔상, 제한 시간, %).
- 일반 몬스터 머리 위 막대를 날렵하게 바꾸고, 월드보스 막대를 키웠습니다.
- 타격감
  - 맞는 쪽이 하얗게 번쩍이고, 내 공격에도 불꽃·파편이 튑니다.
  - 화면 흔들림과 멈칫을 강화했습니다.
  - 데미지 숫자를 굵게 바꾸고 치명타 폭발을 넣었습니다.
  - 스킬 이름 띠, 보스 등장 경고, 진동을 넣었습니다.
- 보스 크기: 스테이지 보스 약 1.5배, 던전 약 1.4배, 월드보스 약 1.8배(캐릭터 키 대비).
- 별의 광산: 광석 덩어리(금 3단계와 파괴), +1 숫자, 콤보, 시간 막대, 등불, 결과 창을 넣었습니다.
- 그림 슬롯 4개(A13~A16)를 미리 연결했습니다. 자세한 내용은 `GPT-전투연출-그림·UI·효과-상세.md`에 있습니다.
